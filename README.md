# 🪷 ลอยกระทงออนไลน์ (Loy Krathong Online)

เว็บแอปพลิเคชันจำลองประเพณีลอยกระทงออนไลน์แบบเรียลไทม์ (Real-time Interactive Web App) ร่วมขอขมาพระแม่คงคา ส่งคำอธิษฐาน และชมกระทงของเพื่อนๆ ลอยไปตามสายน้ำยามค่ำคืนวันเพ็ญเดือนสิบสอง 🌕

## ✨ คุณสมบัติเด่น (Features)

1. **สร้างตัวละครก่อนเข้าสู่งานวัด (Mandatory Profile & Photo Upload)**
   - บังคับสร้างตัวละครก่อนร่วมงาน เพื่อให้ทุกคนมีตัวตนในคืนวันเพ็ญ
   - **อัปโหลดรูปภาพตัวเองจากเครื่อง (Photo Upload)** ย่อส่วนเป็นอวตารวงกลมกรอบทองอร่าม
   - หรือเลือกสร้างตัวการ์ตูนชุดไทย (หญิง, ชาย, ไม่ระบุเพศ) ปรับสีชุดไทยและสีผิวตามใจชอบ
2. **ลานงานวัดริมน้ำ & รอดูคนออนไลน์ (Temple Fair Pier Lobby)**
   - ฉากงานวัดไทยยามค่ำคืน มี**ชิงช้าสวรรค์ประดับไฟหลากสีหมุนเอื่อยๆ**, **ธงราวงานวัด 7 สี**, **สายไฟนีออน**, และ**พระอุโบสถเรืองรองริมน้ำ**
   - แสดงรายชื่อและอวตารของผู้ที่มารออยู่ที่ท่าน้ำแบบสดๆ พร้อมสถานะออนไลน์
3. **ระบบเลือกลอยคู่กันหรือลอยคนเดียว (Couple & Solo Floating)**
   - คลิกที่ใครก็ได้ในงานวัดเพื่อชวน **"ลอยกระทงคู่กัน 💑"** พร้อมแสดงอวตารคู่กันและคำอวยพรคู่
   - หรือเลือก **"ลอยกระทงคนเดียว 🚶‍♂️"** อย่างสงบและเป็นอิสระ
4. **เลือกรูปแบบกระทงหลากหลาย (5 Krathong Styles)**
   - **กระทงใบตองคลาสสิก**: กลีบผกาสีเขียวมรกต ประดับดาวเรืองและกล้วยไม้
   - **กระทงดอกบัวหลวง**: กลีบบัวสีชมพูระเรื่อ สัญลักษณ์แห่งความบริสุทธิ์
   - **กระทงขนมปังรักษ์โลก**: ทรงน้องเต่าขนมปัง ย่อยสลายง่าย เป็นมิตรกับปลา
   - **กระทงกะลามะพร้าวสาย**: กระทงสายสะท้อนแสงไฟสว่างไสว
   - **กระทงนีออนโมเดิร์น**: กระทอร์ดิจิทัลเรืองแสง ไม่สร้างขยะในสายน้ำ
   - ปรับแต่งสีเปลวไฟและแสงเทียนได้ 4 สี (ทอง, ชมพู, ฟ้า, ม่วง)
5. **ระบบอธิษฐานและขอพร (Wish System)**
   - ช่องพิมพ์คำขอพรความยาวสูงสุด 200 ตัวอักษร
   - ปุ่มเลือกคำขอพรมงคลด่วน (รวมถึงคำขอพรคู่รัก)
   - สวิตช์เลือกปล่อยโคมลอยประทีป (Sky Lantern) สู่ท้องฟ้าคืนวันเพ็ญ
6. **จำลองสายน้ำและบรรยากาศ (2D River Canvas Engine)**
   - ผืนน้ำระยิบระยับจำลองคลื่นน้ำแบบ Sine Waves
   - พระจันทร์เต็มดวง แสงเทียนวูบวาบ และโคมลอยล่องลอยสู่ท้องฟ้า
   - กระทงคู่จะแสดงป้าย `💑 [ชื่อ 1] & [ชื่อ 2]` พร้อมกรอบสีชมพูเรืองแสง
   - นำเมาส์ไปชี้กระทงเพื่อดูชื่อและคำขอพรตัวอย่าง
7. **ระบบดูกระทงผู้อื่น & ร่วมส่งกำลังใจ (Community & Reactions)**
   - คลิกที่กระทงของผู้อื่นเพื่ออ่านคำขอพร
   - กดปุ่ม **ส่งใจ ❤️** หรือ **สาธุ 🙏** เพื่อเพิ่มกำลังใจให้เจ้าของกระทง
8. **ระบบเสียงดนตรีบรรยากาศ (Ambient Audio Controller)**
   - สังเคราะห์เสียงสายน้ำไหลและเสียงกระดิ่งระนาดแก้ว/ขิม (Thai Pentatonic Chimes) ผ่าน Web Audio API
9. **รองรับ iPad และโทรศัพท์มือถือทุกรุ่น (Responsive & Touch Gestures)**
   - รองรับ iPad ทั้งแนวนอนและแนวตั้ง
   - รองรับโทรศัพท์มือถือ iOS / Android พร้อมระยะปลอดภัยขอบจอ (Safe Area Insets)
10. **สถาปัตยกรรมเชื่อมต่อ Cloud (Dual-Mode)**
    - **Offline / Demo Mode**: พร้อมเล่นได้ทันทีแบบ Zero-Config
    - **Firebase Realtime Database**: วาง Firebase config ในหน้า UI เพื่อแชร์ให้คนทั่วโลกเล่นสดพร้อมกันได้ทันที

## 🚀 วิธีเปิดใช้งานบนเครื่อง (Local Development)

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. เริ่มต้นเซิร์ฟเวอร์สำหรับพัฒนา
npm run dev
```

เปิดบราวเซอร์ไปที่ `http://localhost:5173`
